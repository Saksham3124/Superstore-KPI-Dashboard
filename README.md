# Business KPI Dashboard — Superstore Sales Analysis

## Overview
End-to-end data analysis project on the Superstore Sales dataset, 
covering data cleaning, exploratory data analysis, SQL querying, 
and interactive Power BI dashboard creation.

## Tools Used
- Python (Pandas, Matplotlib) — data cleaning & EDA
- SQL (SQLite) — business queries & insight extraction  
- Power BI — interactive KPI dashboard

## Key Business Insights
- Total Sales: $2.30M across 2014–2017 with 52% YoY growth
- Profit Margin: 12.47% overall
- West region leads sales at 31.58% of total revenue
- Tables and Bookcases are loss-making despite high sales volume
- Technology category has highest sales and profit margin

## Project Structure
- `analysis.py` — data cleaning, EDA, visualizations
- `queries.py` — SQL business queries via SQLite
- `Superstore_KPI_Dashboard.pbix` — Power BI dashboard
- `monthly_trend.png` — monthly sales trend chart
